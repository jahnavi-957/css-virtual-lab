# Playfair Cipher Virtual Lab

A learning app for exploring the Playfair digraph cipher. It includes a key square, encryption and decryption simulation, step-by-step pair transformations, a randomized Q section, and a responsive blue-and-white interface.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run:

```sh
npm run build
```

## Project structure

- `index.html` is the Vite document shell.
- `src/main.jsx` mounts the React app.
- `src/App.jsx` contains the interface, cipher logic, and interactive state.
- `src/styles.css` contains the page styles and responsive layout.
