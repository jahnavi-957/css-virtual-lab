Aim & objectives

Learn how the Playfair cipher encrypts pairs of letters using a keyword-derived 5×5 key square.

  • Build a square with I and J merged.
  • Prepare messages as digraphs.
  • Apply row, column, and rectangle rules.
02

Theory

In the same row, letters shift right. In the same column, they shift down. Otherwise, each letter takes the other letter’s column.

Same row
Shift right.
Same column
Shift down.
Rectangle
Swap columns.
