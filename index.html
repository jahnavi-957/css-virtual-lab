01

Aim & objectives

To understand and implement the Playfair cipher, a manual symmetric encryption technique that encrypts pairs of letters (digraphs) instead of single letters, and to observe how a keyword-derived key square governs both encryption and decryption.

  • Construct a 5×5 key square from a user-supplied keyword, correctly merging I and J.
  • Split a plaintext message into digraphs, handling repeated letters and odd-length messages.
  • Apply the three substitution rules — same row, same column, and rectangle — to encrypt a message.
  • Reverse the same rules to decrypt a ciphertext back to plaintext.
  • Evaluate why digraph substitution resists simple frequency analysis better than a monoalphabetic cipher, and where it remains weak.
02

Theoretical concepts

The Playfair cipher was invented by Charles Wheatstone in 1854 but is named after Lord Playfair, who championed its use by the British Foreign Office. It was one of the first ciphers to encrypt pairs of letters rather than single characters, which was enough to defeat the simple frequency-counting attacks that broke earlier substitution ciphers.

The key square

A keyword is written out with duplicate letters removed, then the remaining letters of the alphabet are appended in order, filling a 5×5 grid of 25 cells. Since the Latin alphabet has 26 letters, I and J share a single cell — any J in the keyword or message is treated as I.

Preparing the message

The plaintext is split into digraphs (letter pairs):

  • If both letters of a pair are the same, an X is inserted between them and the second letter is carried forward to start the next pair.
  • If the message has an odd number of letters, a trailing X is appended to complete the final pair.

Substitution rules

Each pair of letters is located in the key square, and one of three rules is applied:

Same row

Replace each letter with the one immediately to its right, wrapping to the start of the row if needed.

Same column

Replace each letter with the one immediately below it, wrapping to the top of the column if needed.

Rectangle

The two letters form the corners of a rectangle. Replace each with the letter in its own row but the other letter's column.

Decryption

Decryption uses the identical key square with the row and column shifts reversed — left instead of right, up instead of down — while the rectangle rule stays the same, since swapping columns is its own inverse.

03

Step-by-step procedure

Follow these steps manually before checking your work in the simulation below.

  1. Choose a keyword

    Pick any word or phrase. Remove spaces and repeated letters, and treat J as I.

  2. Build the key square

    Write the unique keyword letters into a 5×5 grid, then fill the remaining cells with the unused letters of the alphabet in order (A–Z, skipping J).

  3. Prepare the message

    Remove spaces and punctuation, convert J to I, then split the text into digraphs — inserting X between repeated letters and padding a final lone letter with X.

  4. Locate each pair in the square

    For every digraph, find the row and column of both letters in the key square.

  5. Apply the matching rule

    Use the row, column, or rectangle rule to substitute each letter, producing the ciphertext (or plaintext, when decrypting) digraph.

  6. Assemble the result

    Concatenate all output digraphs in order to get the final encrypted or decrypted text.
